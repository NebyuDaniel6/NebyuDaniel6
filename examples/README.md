# Example campaign files

These are **in the git repo** so you can download them. Jobs the Cloud Agent ran live only on the remote VM under `data/` (gitignored), so they never appear on your Mac or on GitHub’s default branch.

## Open in Adobe Illustrator (on your Mac)

1. Switch GitHub to branch **`cursor/ai-creative-department-c765`** (not `main`). `main` is still only the profile README.
2. Download this file:

**[illustrator-job.jsx](https://github.com/NebyuDaniel6/NebyuDaniel6/blob/cursor/ai-creative-department-c765/examples/aether-reservations/illustrator-job.jsx)**

Direct download: https://raw.githubusercontent.com/NebyuDaniel6/NebyuDaniel6/cursor/ai-creative-department-c765/examples/aether-reservations/illustrator-job.jsx

3. Open **Adobe Illustrator**.
4. File → Scripts → Other Script… → choose `illustrator-job.jsx`.

Or clone the branch and open the file from disk:

```bash
git clone https://github.com/NebyuDaniel6/NebyuDaniel6.git
cd NebyuDaniel6
git checkout cursor/ai-creative-department-c765
# file is: examples/aether-reservations/illustrator-job.jsx
```
